# PWM 输出设计

## 约束与资源

输出仅使用 PE13 / TIM1_CH3，范围 1 Hz～100 kHz、占空比 0～100%。不包含模拟波形或电压调节。TIM1 由输出模块独占；虽然初始化代码配置了 CH1，但不能再启动 CH1 并独立设置频率，因为所有 TIM1 通道共用 PSC / ARR。

TIM1 使用向上计数、PWM1、高有效、RCR=0。稳态输出不产生周期中断；只有参数更新期间临时开启一次更新中断。关闭输出切回 GPIO 推挽低电平，取消待生效请求。开启和关闭本身是启动 / 停止操作，不保证保留当前脉冲。

## 分频选择

令 `D = PSC + 1`，`N = ARR + 1`，则：

```text
frequency = timer_clock / (D * N)
duty      = CCR / N
```

`D` 取 1～65536，`N` 取 1～65535。保留 `CCR=N` 以直接表示 100% 占空比，避免 16 位 CCR 溢出。定时器时钟根据 APB2、HCLK 和 TIMPRE 推导，不写死为 240 MHz。

求解器比较精确的频率误差 `abs(clock - target * D * N) / (D * N)`，使用 64 位整数交叉相乘；不先四舍五入成 Hz 或 mHz 再比较。误差相同则优先选更大的 `N`，提高占空比分辨率。占空比 CCR 采用最近整数舍入，量化误差不超过半个计数。

当 `clock / target <= 65535`，最接近理想周期的相邻整数都可由 `D=1` 实现，因此只需一次候选计算。其余情况利用因子互换：在两因子都可交换时，`D>N` 的解可换成同频率且更高占空比分辨率的解，搜索到平方根即可；不能互换的 `D=65536` 单独检查。找到精确频率后按搜索顺序提前结束。边界验证限制计算时钟为 1～550 MHz，以确保乘积和 mHz 表示不溢出；这个上限仅是算法输入约束，不代表芯片外设可超频到该值。

最坏搜索不超过 23,454 个分频值，常用频率远少于此。搜索在任务上下文、临界区之外执行，可以被采样和 CAN 任务抢占。主机运行时间不能代替 MCU 实时性测量。

以标称 240 MHz 时钟、1 Hz 输出为例：原先取首个可用分频值得到约 1.000001 Hz；新算法选择 PSC=3749、ARR=63999，数学上正好为 1 Hz。实际引脚仍受晶振误差影响。频率误差最小是第一优先级，界面显示的实际计算占空比可能与 0.1% 设置有少量量化差异。

## 周期边界更新

PSC 自带预装载；模块显式开启 ARR 的 ARPE 和 CCR3 的 OC3PE，保证三者在同一个更新事件转入有效寄存器。URS=1 使软件 UG 不触发本模块的周期更新中断，初始化时仍可用 UG 装载寄存器。

运行中修改参数遵循以下顺序：

1. 在临界区外验证请求并求解定时器参数。
2. 进入 FreeRTOS 临界区，置 UDIS，暂时禁止更新事件及影子寄存器传送，计数器继续运行。
3. 如果旧请求已在硬件生效但中断尚未处理，先通过 UIF 将旧请求记为已生效。
4. 写入 PSC / ARR / CCR3 预装载寄存器并保存最新请求，清除旧 UIF，开启 UIE。
5. 清除 UDIS 并退出临界区，下一次自然溢出同时提交三个寄存器。
6. TIM1_UP 中断关闭 UIE、清除 UIF，将请求转为已生效状态。

运行中不写 CNT，不调用 PWM Stop / Start，不产生软件 UG，避免截断或人为重启当前周期。若自然溢出恰好发生在 UDIS 窗口内，硬件继续完整的旧周期，参数等到下一次允许的边界生效。重复修改尚未生效的参数采用最新请求；关闭立即取消全部待生效操作。

TIM1_UP IRQ 优先级使用 `configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY`（当前为 5），确保任务临界区确实能够屏蔽它。ISR 不调用 RTOS API、不求解分频、不绘制 LCD。已挂起但迟到的 NVIC 中断通过 UIE / UIF / pending 门控处理，不能重新开启已关闭的输出。

## 状态与显示

输出驱动持有唯一状态源：requested、applied、已生效 timing、pending、ready、error、failures 和 revision。LCD / USB 使用 `BusScope_OutputSnapshot` 一次性读取；快照还会处理已发生但 ISR 尚未接收的更新事件。

`OUT` 中的设置代表最新请求，计算频率属于 applied。新增 `OUTSTAT` 明确给出 pending 与 applied 设置，并报告 PSC / ARR / CCR。字段是计算状态，不是测量读数；恒低 / 恒高仍保留内部定时器频率。错误请求不会破坏正在输出的有效 PWM；真正启动失败则将引脚拉低。

LCD 保留上一帧每行文字和颜色，只刷新发生变化的行。换页强制全量刷新，避免旧内容残留。频率步进是编辑设置，不会触发硬件重启。

## 验证与上板验收

主机测试使用独立按 ARR 穷举的参考实现验证分频选择，覆盖不同定时器时钟、非整分频、端点和占空比舍入。硬件模型区分预装载值与有效值，能在寄存器写入之间插入溢出、延迟 IRQ，并验证停止、失败和嵌套临界区。应用测试检查快照一致性、整帧与增量绘制一致、文字边界及无变化时零重绘。

主机模型和 Keil 编译不能验证实物时序，烧录后建议用外部示波器或逻辑分析仪完成以下验收：

| 场景 | 预期 |
| --- | --- |
| 1 Hz、37 Hz、997 Hz、99991 Hz、100 kHz | 周期与计算值在时钟公差内一致 |
| 占空比 0%、0.1%、50%、99.9%、100% | 两端恒低 / 恒高，中间脉宽与 CCR 量化值一致 |
| 运行中改变频率 / 占空比 | 当前完整周期结束后更新，没有 Stop / Start 导致的额外短脉冲 |
| 1 Hz 下连续调参并查看 USB | 先显示 pending，最终 applied 与最新请求一致 |
| pending 时关闭并再次开启 | 关闭立即低电平，旧请求不会被迟到中断恢复 |
| 三路 CAN 有负载时反复调参 | PWM 硬件输出持续，采样延迟 / 丢帧统计可用于观察调参开销 |

板载示波器仍以 2 ms 间隔采样，只适合低频观察，不能代替高频 PWM 的外部测量。
