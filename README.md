# DM-MC02 BusScope

## 项目介绍

基于 DM-MC02（STM32H723VG）的总线监测、低频示波器和 PWM 输出工具。可同时查看三路 CAN / CAN-FD 的帧率、接收数量和最新报文，用板载 LCD 显示模拟波形、估算 PWM 频率和占空比，并通过 PE13 输出可调频率和占空比的 PWM。

USB 虚拟串口每 500 ms 输出一次状态快照，最新 CAN-FD 报文最多输出 64 字节。它不记录完整的 CAN 历史数据。

## 使用说明

### 编译与烧录

用 Keil MDK（ARM Compiler 5）打开 [DM_MC02_BusScope.uvprojx](MDK-ARM/DM_MC02_BusScope.uvprojx)，选择同名目标并编译。也可在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File Tools/build.ps1 -Rebuild
```

脚本可用 `-Uv4Path` 指定 Keil 路径。通过 SWD 烧录生成的 `MDK-ARM/DM_MC02_BusScope/DM_MC02_BusScope.hex`。

### 接线

| 功能 | 连接 |
| --- | --- |
| 波形输入 | PA0，与信号源共地，输入范围 0～VDDA（按 3.3 V 换算） |
| PWM 输出 | PE13，与接收设备共地；上电默认 10 Hz、50%，高电平约 3.3 V |
| CAN | 连接对应通道收发器侧的 CANH / CANL，并核对共地和终端电阻 |
| USB | 用数据线连接开发板 USB 设备接口 |

PA0 不能输入负电压或超过 VDDA 的信号。屏幕负电压刻度仅用于显示偏移，不代表引脚支持负压。

三路 CAN 默认仲裁速率为 1 Mbit/s、数据速率为 5 Mbit/s；需与所接总线一致。固件使用 Normal 模式，会参与 ACK。

### 页面操作

上电进入 CAN 页面，显示各通道最新报文的 ID、长度、前 8 字节数据，以及帧率和累计接收数。按 OK / SELECT 依次切换 CAN → 示波器 → PWM 输出 → CAN。切换页面不会停止输出。

| 按键 | 示波器操作 |
| --- | --- |
| OK / SELECT | 切换 CAN / 示波器 / PWM 输出页面 |
| 上 / 下 | 选择 TIME / MODE / EDGE / TRIGGER / Y GAIN / Y OFFSET / ARM |
| 左 / 右 | 减小 / 增大当前参数，或切换模式 |

### 示波器

PA0 改为 TIM6 硬件触发、100 kSa/s 连续 DMA 采样，原始采样间隔 10 us。每帧显示 272 个采样区间，各区间保留最小值、最大值和均值。慢时基仍按 100 kSa/s 采集，窄脉冲不会因简单抽点被丢弃；短于原始采样间隔的脉冲仍可能漏采。

| 参数 | 范围 / 行为 |
| --- | --- |
| TIME | 每显示区间 10 / 20 / 50 / 100 / 200 / 500 / 1000 / 2000 us；全屏刻度跨度 2.71～542 ms，默认 13.55 ms |
| MODE | AUTO 无触发时约两帧时间后刷新；NORMAL 等待有效触发；SINGLE 捕获一次后停止；HOLD 保留最后一帧 |
| EDGE | 左键下降沿，右键上升沿 |
| TRIGGER | 50～3250 mV，步进 50 mV，默认 1650 mV，触发回差 ±25 mV |
| Y GAIN | 0.1～8.0 倍，步进 0.1 倍 |
| Y OFFSET | -10000～10000 mV，步进 100 mV；仅改变显示位置 |
| ARM | 左键冻结；右键重新开始当前采集模式，HOLD 下右键启动 SINGLE |

触发点位于第 68 个区间，约四分之一屏，黄色标记指示触发位置；底部时间从本帧左边界计时。修改采集参数会丢弃未完成帧；HOLD 下保留原记录及其时间刻度，恢复采集后采用新参数。冻结期间仍可调整纵向显示和切换页面，按键 ADC 继续工作。

屏幕显示峰峰值 PP、总有效值 RMS（含直流）、平均值 AVG、频率 F 和高电平占空比 D。测量使用原始数据，而非显示抽取后的点。频率测量要求帧内至少两个完整周期，每周期至少 10 个原始采样点，高低电平各至少两个点；测得周期差异过大时显示 `--`，检测到采样点不足时标记 `UNDERSAMP`。测量边沿使用当前触发电平，故电平必须落在信号高低值之间。

100 kSa/s 是采样率，不是模拟带宽或可测方波频率。当前算法最多接受约 10 kHz 的频率估计，窄占空比要求更低频率；高于奈奎斯特频率的输入仍可能混叠成低频，需外部限带，不能依靠软件诊断排除。PA0 没有新增衰减、放大、保护或抗混叠前端，也不能分析 CAN 位时序。

自测可将 PE13 接到 PA0 并共地：PWM 设为 1 kHz、50%，使用默认示波器时基；测试默认 10 Hz PWM 时，把 TIME 调大到约 67.750 ms/div（全屏 271 ms）或更慢。高频输出请用外部示波器测量。

### PWM 输出

| 项目 | 范围 / 行为 |
| --- | --- |
| 频率 `FREQ` | 1 Hz～100 kHz |
| 频率步进 `STEP` | 1 / 10 / 100 / 1000 / 10000 Hz，默认 10 Hz |
| 占空比 `DUTY` | 0～100%，步进 0.1% |
| 输出 `OUTPUT` | `ON` 开启，`OFF` 时 PE13 拉低；启动失败时显示 `ERROR` 并拉低 |

上 / 下选择参数，左 / 右减小 / 增大；输出开关左关右开。`STEP` 控制频率调整步长，因此可按 1 Hz 精调任意整数频率。运行中更改频率或占空比，会在下一个允许的周期边界同时更新，等待时显示 `ON (PENDING)`；连续修改只保留最新请求。调整 `STEP` 不会重启输出。关闭输出立即拉低 PE13；断电后恢复默认 10 Hz、50% 占空比、输出开启。

`ACT` 和 `D` 显示已经生效的计算频率与占空比，下面列出对应 PSC、ARR、CCR 寄存器值。这些是根据定时器时钟计算的结果，并非引脚实测值；时钟误差和计数器量化仍会影响实际信号。调参期间，设定值与 `ACT` 可暂时不同，低频下尤其明显。屏幕仅更新发生变化的行。

输出使用 PE13（TIM1_CH3），电平约 0 / 3.3 V，没有电压调节。直接把 PE13 接到目标设备输入并共地，无需外接滤波器。0% 占空比保持低电平，100% 保持高电平。PWM 由 TIM1 硬件持续产生，不使用波形采样表、调制 DMA 或额外定时器。

### USB 查看

连接 USB 后，用串口工具打开枚举出的虚拟串口，选择 115200、8N1。输出为文本 CSV：`CAN1～3` 是最新报文，`STAT1～3` 是通道统计，`SYS` 是 ADC、输出模块就绪和采样状态。LCD 通道标题变红时，检查通道初始化和 bus-off 状态；排除总线问题后重启设备。

PWM 状态由同一份原子快照生成：

```text
OUT,PWM,设定频率Hz,设定占空比千分比,请求开关,就绪,已生效计算频率mHz
OUTSTAT,待生效,已生效设定频率Hz,已生效设定占空比千分比,实际开关,PSC,ARR,CCR,错误码,累计失败次数
```

`OUT` 保留原有字段顺序。`待生效=1` 时，`OUT` 的设定值还未全部生效，应以 `OUTSTAT` 和计算频率判断当前输出。关闭时计算频率与 PSC / ARR / CCR 诊断字段为 0，已生效设定值仅保留配置；`就绪=1,实际开关=0` 表示模块正常但输出关闭。错误码：0 正常、1 未初始化、2 参数无效、3 时钟或分频计算失败、4 启动失败。无效请求会被拒绝并保留当前输出；启动失败会拉低 PE13。

### 本机测试

运行 `powershell -ExecutionPolicy Bypass -File Tools/test.ps1`，需要 GCC。测试包含分频结果与独立穷举算法的对照、占空比量化边界、定时器预装载 / 中断模型、页面增量刷新和一致的 USB 状态快照，并回归原有 ADC 示波器与 CAN / USB 逻辑。硬件 PWM 频率、占空比和电平需要烧录后用示波器实测。

定时器更新机制、精度约束与上板验收方法见 [PWM 设计说明](Docs/PWM_DESIGN.md)。

示波器增加以下 USB 诊断行；`SYS` 的后两项分别为显示未消费的帧数和 DMA 丢块数，LCD 刷新慢导致跳帧与原始采样丢块分别计数：

```text
SCOPE,帧序号,原始采样率Hz,该帧区间us,请求模式,请求下降沿,请求触发mV,等待,停止,最小mV,最大mV,峰峰mV,平均mV,RMSmV,频率mHz,占空比千分比,频率有效,采样不足,帧配置有效
ADCSTAT,成功数据块,丢块,错误,成功重启,最后错误码
```

模式值依次为 AUTO=0、NORMAL=1、SINGLE=2、HOLD=3。统计数据属于最近完整帧；调整参数后、首帧到来前，`帧配置有效=0`。HOLD 保留原帧。ADC 错误时会停止触发并在任务中尝试恢复，不在中断中校准或重启。设计细节、诊断说明和上板验收见 [示波器设计说明](Docs/SCOPE_DESIGN.md)。
